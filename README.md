# Early Prediction of Student Dropout and Academic Success

## Overview
This project investigates the use of classical machine-learning models to predict student academic outcomes in higher education.

## Research Question
How effectively can machine-learning models predict students' final academic outcomes using information available at enrollment?

## Dataset
- **Source:** UCI Machine Learning Repository
- **Dataset:** Predict Students' Dropout and Academic Success
- **Task:** Three-class classification — dropout, enrolled, and graduate

## Methods
Planned models:
- Baseline classifier
- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation
Models will be evaluated using macro-F1, per-class recall, and a confusion matrix, alongside accuracy where appropriate.

## Project Structure
- `data/` — dataset files
- `notebooks/` — analysis and experiments
- `reports/` — figures and project findings

## Status
In progress — setting up the environment and inspecting the dataset.

## Limitations
This is an educational research project. Model performance and feature relationships should not be interpreted as evidence of causation or as a validated student-intervention system.
